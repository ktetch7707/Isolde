## Interaction changes

| Audit finding | Revised interaction |
| --- | --- |
| Technical Add catalog | Six everyday choices first: App shortcut, App row, Media shelf, Text, Image, Clock. More components retains sources, shapes, groups, Guide and other tools. |
| Property categories before tasks | Edit component opens a type-specific summary of content, labels, artwork/links as applicable, Style and Size. Advanced opens the complete inspector. |
| Too many appearance fields | Style presets first; Customize exposes a short relevant field list. Per-section Advanced retains precise presentation and state controls. |
| Page styling mixed with architecture | Page summary: Theme colors, Background, Header, Page layout, Advanced. Header begins with title/logo/clock/buttons. Interface appearance and page links live in Advanced. |
| Action-system vocabulary | One basic When selected field leads with Open an app, Go to a page, Open media, More actions and No action; search and categorized detailed actions remain. |
| Overloaded Layers | Page items offers Find on page, Edit, Hide/Show and Lock/Unlock. Select multiple is explicit; Advanced navigation and Header remain reachable. |
| Fourteen reuse operations together | Saved styles and My components each have short Use/Save/Manage menus. Connected copies are explicit. Responsive rules belong to advanced Page layout. |
| Designs hidden behind operations | Design library opens the gallery with actual bounded layout thumbnails, defaults to current-page preview, and offers whole-interface use explicitly. Import/export/reference controls live under Manage designs. |
| Product changes in editor settings | Editor settings contains Canvas view and Studio colors. All Apps appearance and page reset belong to page management. Whole-interface recovery is separate. |
| History begins with destructive tools | Versions are listed first beside Undo/Redo. Compare precedes restore. Rename/delete/clear are under management; restoring the interface requires an explicit scope choice. |

Save changes and Exit stay fixed at the bottom of the main panel. The main panel does not grow with the number of pages. Save opens the multi-page change summary with Save, Keep editing, Try for and Try changes. Findings appear only when present. The trial presets are 30 seconds, 1 minute and 5 minutes. Back or expiry restores the edit origin and reopens the save dialog; neither writes nor discards the draft. The existing draft navigation/external-effect interception remains explicit.

## Five-color themes

Five shared colors are Background, Cards, Text, Highlight and Accent. Each row opens the individual roles. Its separately focusable swatch edits the shared color. Right/Left selects the swatch/row on a remote; pointer targets use the same operations. Individual roles indicate their source and offer Use theme color. A custom role survives later shared-color changes; explicitly reconnecting removes that override. Scheme selection is one draft transaction.

New packaged defaults link all roles to the five colors; stored older layouts retain their explicit choices. The optional version-1 `theme.colorTheme` object stores five opaque shared colors. Existing top-level theme role values remain explicit overrides. The native resolver derives colors without modifying stored documents. Older documents retain their appearance and are not migrated on read; a legacy page's single text color retains its original interpretation. Invalid palette versions, unknown/missing groups and nonopaque/invalid colors are refused before draft acceptance. Existing component-specific presentation overrides retain precedence.
