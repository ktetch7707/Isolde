# T14 provider and Linguist implementation notes

## Discovery provider decision

The conservative metadata/provider-listing choice is **The Movie Database (TMDB) API v3**. The production adapter uses the explicit `/search/multi` route for movie/TV identity, then `/{movie|tv}/{id}/watch/providers` for a user-selected two-letter region. It sends a request only after the profile's persistent Web preference is ON and a query of at least two characters is open. The read token is supplied through `ISOLDE_TMDB_READ_TOKEN`; it is not persisted in settings or logged. Missing configuration produces a visible local-only state and makes no request.

Searches are bounded to 200 input characters, a 2 MiB response, and 20 accepted results. The region is persisted under the active profile's Search settings; the remote offers common-region D-pad cycling and a remote keyboard for any two-letter ISO region code. Each result gets a request-time UTC timestamp and a media-type/provider-ID/year identity so remakes and separately identified releases are not merged. Results are memory-only; switching Web OFF, closing Search, shortening the query below two characters, changing region, or beginning another query aborts in-flight replies and clears old title and provider listings. Provider listings are observations, not proof of subscription, playback rights, account access, or current availability.

Selecting a known provider listing opens its official HTTPS title-search route for Netflix, Prime Video, Hulu, Crunchyroll, Disney+, Apple TV, Peacock, Paramount+, or Max. Unsupported provider IDs remain informational. These are service search routes—not guaranteed title-specific playback deep links—and open only after the user selects a listing while Web is ON. Search routes do not imply app installation, sign-in, availability, access, or entitlement.

The official, unmodified TMDB “Primary short (blue)” logo is bundled at `assets/tmdb-logo.svg`, with its source and handling notice beside it. The required disclaimer appears in the online-search UI and the System → About Isolde attribution page, which also links to `themoviedb.org`. These provider notes point to TMDB's official attribution guidance. TMDB states that commercial use may require a separate license; confirm the intended deployment's license before distribution. Provider responses and service-route generation are exercised with local fixtures; no live account or credentials are needed by the focused contract test.

## Offline subtitle choices

The existing-SRT translation adapter invokes **Argos Translate CLI** once per cue with `--from-lang`, `--to-lang`, and `--text`. The conservative audio-generation path invokes **whisper.cpp CLI** in local translate mode using an already-present multilingual `.bin` model. Both processes are started directly with argument vectors; there is no shell command construction, media upload, implicit package installation, or model download. Missing executables/language packs/models fail visibly and retain the input.

Only a specifically selected UTF-8 SRT or media file is queued; no whole-library jobs are created. The explicit queue is bounded to 16 jobs. SRT input is bounded (8 MiB / 10,000 cues / 16 KiB per cue), cue headers/timecodes are preserved for translation, results are written atomically to a non-colliding language-suffixed file, and a provenance sidecar records tool, source hash, languages, UTC creation time, offline-only processing and review requirement. If the media folder is not writable, output is stored under Isolde's managed cache. Cancelled or failed work does not replace a source or completed output. Completed SRT can be reviewed and atomically edited before Kodi is asked to load it through its supported local player API. Forgetting a queue record never deletes its output or provenance.

Machine translation/transcription quality is not certified. Outputs require review. The Argos runtime and Whisper executable/model remain operator-installed prerequisites; this slice does not ship model downloads. Audio-generation input must be a selected local media file, not a stream.

Argos language packs can now be explicitly imported from a local `.argosmodel` archive using the installed Python Argos package API; the UI also refreshes the installed source/target pair inventory. The import path validates local file type/size, runs a bounded helper process, never contacts a package index, and reports failures visibly. Whisper models remain local operator-managed prerequisites.

Web ON additionally enables a separate OpenSubtitles.com API adapter when `ISOLDE_OPENSUBTITLES_API_KEY` is configured; an optional short-lived `ISOLDE_OPENSUBTITLES_TOKEN` is sent only to the API host. A user must explicitly search by title, media type, and language, select an SRT result, and confirm download. Only the title/language query and selected file ID are sent; no local media or subtitle is uploaded. Download links are freshly requested, HTTPS host-allowlisted, fetched without forwarding API credentials, bounded to 8 MiB, and plain UTF-8 SRT only; archives/binary formats are refused. Downloaded files are stored in the active profile's managed cache with source/hash/provenance, an explicit online marker, no-overwrite handling, and review required. Web OFF cancels requests and clears result state. API credentials are read from the environment, never settings or logs.

The subtitle queue includes heuristic output checks for cue count, timestamps, empty/short cues, and possible unchanged source text. Reports are persisted with provenance and shown in the UI; they explicitly say language quality is not certified and human review is required. Review saves also update the provenance sidecar with a review timestamp and structural report, rolling back the subtitle edit if the sidecar cannot be committed.

Kodi subtitle-track discovery and selection use `Player.GetProperties` / `Player.SetSubtitle` only for the currently owned managed local video. The remote opens a track picker with Menu during playback; track IDs are validated against Kodi's current track list, including an explicit Off option. Foreign, replaced, stream, and unmanaged players are refused.

Remaining deliberately out-of-slice work is `.ass` translation, automated speech alignment, translation-quality certification, streaming subtitles from media streams, and automatic model/package downloads. Provider search links are official service search entry points rather than provider-specific title playback URLs; TMDB does not establish entitlement or supply those app deep links. Live-provider credentials/service behavior, API account status, commercial license confirmation, and VM acceptance are external verification/deployment matters, not missing code in these paths.
