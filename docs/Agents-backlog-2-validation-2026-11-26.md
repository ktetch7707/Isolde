## Repair checkpoint on the same branch

The first repair batch preserves the branch history and its implementation. It brings the Studio catalog back within the existing 128 KiB cap without changing the parsed catalog data and accepts both legacy and explicit v1 action categories. It packages the slot inspector and resume dialog, handles an empty slot selection, and makes Back cancel the resume prompt. Clean now uses the bridge-owned confirmation parameters and the existing scalar acknowledgement path. Its UI requires an explicit confirmation and respects profile editing permission. The watched-write adapter translates Isolde's edit object into Kodi's top-level parameters and refreshes the active page after Kodi confirms. The library exposes the action on episode and movie details.

The two targeted Python bridge tests passed on the host. Windows lacks the Unix socket and POSIX ownership APIs used by other bridge tests, so their verdict belongs to the Linux VM. The unchanged full-suite failure receipts above remain the comparison baseline. The first repair attempt stopped during snapshot creation because a source file changed while the archive was being generated. The next run uses the frozen batch.
