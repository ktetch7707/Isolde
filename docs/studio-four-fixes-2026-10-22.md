## Changes

1. **Individual history-card navigation.** `ComposedHome` enters a collection as focus arrives and forwards Left/Right/Confirm directly when a collection is the initial focused item. No extra Confirm is required to unlock its cards. Confirm activates the selected real media item; Back/Up/Down retain collection/page recovery paths. Native regression moves right and left between media identities and plays with one Confirm.
2. **Library destinations are editable pages in Pastel.** Packaged Movies/TV buttons now use validated open-page actions. The two starter pages contain real `library` components, ordinary grid placement, shared theme inheritance, configurable source/card layout and page navigation. Kodi continues to own metadata and playback. Skin-level declarative `pagePolicy: add-missing` validates starter documents, preserves all authored pages, adds missing starter identities atomically and retains edits to an existing starter on reapplication. Whole-interface saved-skin semantics remain unchanged; applying a page-set skin from a child page refuses with a clear error. No startup migration or silent rewrite of existing layouts occurs. Legacy layouts' existing built-in browser fallback remains compatible; users adopt the new destinations by explicitly applying Pastel or linking their own pages.
3. **Carousels in Studio.** Opening Studio defaults to all sections, rather than silently isolating the first section. Explicit section isolation stays available. The real Home renderer displays the app/history rows; Studio media keys are separate from runtime page-client keys so draft source changes do not retarget a live Home client. Preview still intercepts activation and freezes data during gestures.
4. **Spatial color wheel.** D-pad moves the target horizontally/vertically in screen coordinates. Repeated Left travels left across the wheel, through white at the center, rather than rotating hue. Movement stays within the circular boundary. Pointer and remote converge on identical saved colors; brightness remains separate, Back exits adjustment, and canceled previews/Undo remain unchanged. The earlier polar-input requirement in the usability audit is corrected.
